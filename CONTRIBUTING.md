# Contributing

Bug reports and focused pull requests are welcome.

Before submitting a change:

1. Keep the app offline-first and avoid broad storage permissions.
2. Do not add code, assets, or branding copied from the inspiration project.
3. Preserve the provider's read-only contract.
4. Run `gradlew testDebugUnitTest lintDebug assembleDebug`.
5. Test both portrait and landscape when changing layout code.
6. Explain any new permission in the pull request and in the privacy policy.

Do not commit signing keys, passwords, game files, or proprietary JoiPlay
sources/APKs without explicit redistribution permission.
