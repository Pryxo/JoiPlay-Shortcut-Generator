# Changelog

- Live JoiPlay library backed by the patched read-only provider.
- Direct game launch and Android home-screen pinning.

- Persistent output-folder selection through Android's document picker.
- Theme, sorting, tap behavior, and folder-entry settings.
- Responsive original phone/tablet UI and public-release documentation.
